# Segurança

## Relatar vulnerabilidades

Não publique detalhes exploráveis, agendas reais, backups ou credenciais em issues e pull requests. Se o GitHub exibir **Report a vulnerability** na aba Security deste repositório, use esse canal privado. Se o canal não estiver disponível, abra uma issue apenas solicitando um contato privado, sem detalhes da vulnerabilidade.

## Dados locais

A agenda fica no navegador e não é enviada para um banco de dados do projeto. O armazenamento local não é criptografado pela aplicação: pessoas com acesso ao mesmo perfil podem ler os dados. Limpar os dados do site pode apagar a agenda. Armazenamento persistente não substitui backup.

Proteja o dispositivo, guarde backups em local privado e não use as notas para senhas ou segredos. Importações validam formato e referências, mas arquivos desconhecidos devem ser tratados com cautela. Não há auditoria completa de segurança ou garantia de ausência de vulnerabilidades.
