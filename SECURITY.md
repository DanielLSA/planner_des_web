# Segurança

Não inclua agendas reais, backups ou credenciais em issues e pull requests. Para relatar vulnerabilidade, use o canal privado de segurança do repositório quando disponível. O mantenedor precisa configurar esse canal antes da publicação pública; nenhum contato fictício é fornecido.

O armazenamento local não é criptografado pela aplicação. Pessoas com acesso ao perfil do navegador podem ler os dados. Use proteção do dispositivo e guarde backups em local privado. Não use o Planner para armazenar senhas ou segredos.
