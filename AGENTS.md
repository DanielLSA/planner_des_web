# Convenções

Leia docs/PRODUCT.md e docs/ARCHITECTURE.md antes de mudar comportamento. Preserve dados locais, sem IA/analytics. Não versionar dados reais, segredos, node_modules ou dist.

Comandos: `npm ci`, `npm run dev`, `npm test`, `npm run build`. Testar regras de domínio ao mudar recorrência, datas, backup ou conflitos. Verificar interface em desktop e celular após mudanças visuais. Atualizar requisitos e docs/STATUS.md na mesma entrega.
